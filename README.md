# 단어 트레이너

영어 단어 암기 도우미. 서버 없이 브라우저만으로 동작하는 정적 웹 앱입니다.

## 실행

- **PC:** `index.html`을 더블클릭해서 엽니다.
- **로컬 서버로 실행 (오프라인 캐시, 홈 화면 추가 가능):**
  ```bash
  python -m http.server 8123
  ```
  그다음 `http://localhost:8123`에 접속합니다.
- **모바일:** 이 폴더를 GitHub Pages, Netlify 같은 정적 호스팅에 올려 HTTPS 주소로 엽니다. 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

처음에는 설정 화면에서 Claude API 키를 입력합니다. 키가 없으면 `단어 = 뜻` 형식으로만 등록할 수 있고, 이때는 유형 1 문제만 출제됩니다.

## 데이터 저장 위치

| 위치 | 내용 |
|---|---|
| 브라우저 localStorage | 기본 저장소. 브라우저(그리고 주소)마다 따로 저장됩니다. |
| 연결된 JSON 파일 | PC의 Chrome/Edge에서 설정 → "새 파일 만들어 연결"을 하면, 바뀔 때마다 그 파일에 자동 저장합니다. |
| 내보내기 파일 | 설정 → 내보내기. 단어장 하나 또는 전체를 JSON으로 저장합니다. 다른 기기에서 "파일 가져오기"로 합칠 수 있습니다. |

API 키는 localStorage에만 저장되고, 단어 파일에는 들어가지 않습니다.

## 문제 유형

1. **뜻 보고 단어 쓰기:** 한글 뜻과 첫 글자를 보고 단어를 씁니다.
2. **예문 빈칸 채우기:** 예문의 빈칸을 채웁니다. 첫 글자와 한글 뜻이 주어집니다.
3. **한글 문장 영작:** 유형 2의 예문을 한글 번역으로 보고 영작합니다. 빈칸 수가 곧 단어 수이고, 힌트 단어가 주어집니다. 대소문자와 문장부호는 무시하고 기준 문장과 완전히 같아야 정답입니다.

단어 대신 구문(phrasal verb, 숙어, 연어)도 같은 방식으로 등록할 수 있습니다. `bank (river)`처럼 괄호 안에 쓴 내용은 뜻이나 상황을 정하는 참고 메모로 쓰이고, 단어에는 들어가지 않습니다. 뜻이 여러 개인 단어는 뜻마다 따로 등록되고, 퀴즈에서 상황 힌트로 구분합니다. 정답이면 익힘도 +1, 오답이면 -1(최소 0)입니다. 테스트는 익힘도가 낮은 단어부터 출제하고, 익힘도가 같으면 무작위로 고릅니다.

이미 등록된 단어를 다시 넣으면 미리보기에서 "중복"으로 표시되고 기본으로 등록에서 빠집니다. "다른 뜻으로 추가"를 누르면 Claude가 아직 등록되지 않은 다른 뜻을 찾아 줍니다. 필요하면 체크를 켜서 그대로 등록할 수도 있습니다.

## 발음

문제를 푼 뒤 해설, 단어 상세 화면, 결과 화면에 스피커 아이콘이 나옵니다. 누르면 바로 재생됩니다.

- 녹음 파일은 Wikimedia Commons의 원어민 녹음(미국식 우선)을 쓰고, 발음 기호(IPA)는 Free Dictionary API에서 가져옵니다.
- 녹음이 없는 단어와 구문은 브라우저 음성 합성으로 읽습니다.
- "사전" 링크는 Cambridge Dictionary의 해당 단어 페이지를 엽니다.
- 한 번 찾은 결과는 단어 데이터에 저장되어 다음부터는 바로 재생됩니다.

새 문제 유형은 `js/quiz.js`의 `types`에 항목을 하나 추가하면 됩니다.

## 파일 구성

- `js/store.js`: 단어장 데이터, localStorage, 가져오기/내보내기, 파일 자동 저장
- `js/claude.js`: Claude API로 뜻, 예문, 힌트 생성 (모델과 프롬프트)
- `js/pron.js`: 발음 찾기와 재생
- `js/quiz.js`: 문제 유형과 출제 로직
- `js/app.js`: 화면과 라우팅
